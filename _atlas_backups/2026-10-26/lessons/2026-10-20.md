## 1. What was learned

### 1.1 arxiv 2603.22455 — *SkillRouter* (Alibaba Group) — HIGH
First systematic study of **skill routing**: ~80K-skill pool, 75 expert-verified queries, benchmark built
from SkillsBench. The finding that matters is negative: *"Current agent architectures adopt a progressive
disclosure design — exposing only skill names and descriptions to the agent while keeping the full
implementation body hidden — implicitly treating metadata as sufficient for selection. We challenge this
assumption."*

- Removing the body costs **29–44 percentage points** across all retrieval methods.
- Cross-encoder attention: **91.7% concentrates on the body field**.
- Rerankers given metadata only are *actively harmful* (worse than no rerank).
- Their pipeline: bi-encoder retrieval + cross-encoder rerank, listwise loss (**+30.7pp** over pointwise),
  false-negative filtering (+4.0pp), 74.0% Hit@1 at 0.6B.
- arxiv 2606.03565 (*Skill Is Not Document*) independently reports 31–44pp from hiding the body and adds
  the multi-skill requirement: **"minimal yet sufficient"** — a missing skill makes the task unsolvable,
  a conflicting one creates new failures.

**Why this matters here:** we have no retriever. Our selection step is the LLM planner reading
`- <name>: <description>` rows truncated to 57 chars. So the paper's regime (retrieve-then-rerank on
bodies) is inverted: at our scale the *description prefix is the entire selection signal*, and any two
skills that say the same thing are a coin flip. That is a measurable defect we had never checked.

### 1.2 arxiv 2601.10338 — *Agent Skills in the Wild* — HIGH
42,447 skills collected from two marketplaces, 31,132 analysed with **SkillScan** (static analysis + LLM
semantic classification; 86.7% precision, 82.5% recall). Numbers:

- **26.1%** of skills carry ≥1 vulnerability, across **14 patterns in 4 categories** (prompt injection,
  data exfiltration, privilege escalation, supply chain).
- Data exfiltration **13.3%**, privilege escalation **11.8%**; **5.2%** show high-severity patterns
  strongly suggesting malicious intent.
- **Skills bundling executable scripts are 2.12× more likely to be vulnerable than instruction-only
  skills (OR = 2.12, p < 0.001).** ← the actionable triage split.
- Recommendation: capability-based permission systems + mandatory vetting before installation.

The 26.1% baseline we already carried from NVIDIA's writeup is this study. The *odds ratio* is the new
part, and it reorders our audit effort: read code where code exists, text where it does not.

### 1.3 Hermes docs — *Which File Does What?* — OFFICIAL
Maps six files to six jobs. The load-bearing detail: **SOUL.md is system-prompt slot #1**, lives at
`$HERMES_HOME/SOUL.md`, is independent of the project-context chain (`.hermes.md` → `AGENTS.md` →

This closes last week's open item: the sweep tried to write `~/AGENTS.md` as the always-resident carrier
and was blocked by the protected-instruction-file guard. The correct carrier was never AGENTS.md — it is
`~/.hermes/SOUL.md`, and it accepted the edit.

### 1.4 Hermes docs — *Recurring Loops* (`/loop`) — OFFICIAL
Timer-driven in-session repetition: `/loop 5m <prompt> [--times N] [--until <cond>]`. Fixed interval when
an external clock drives the work; **self-paced** (no interval) backs off 1m → 2m → 4m → 8m → 15m while
replies stop changing, and snaps back on any change — change detection is a local digest, so idle waits
cost nothing. Stops on `LOOP_COMPLETE`, a run cap, an evidence-based `--until` judged by the same
auxiliary judge as `/goal`, or `max_ticks` (default 100) as the token backstop. Session-scoped: cron is
the unattended equivalent and the only one that survives restarts.

## 2. What changed

### 2.1 New tool: `~/.hermes/scripts/skill_routing_collision_check.py` (pipeline step 7)
Scores every discoverable pair per root on the **57-char rendered prefix** (token Jaccard + difflib) and
tiers by `diverge_at` — the character where the two descriptions stop agreeing. `< 8` fine, `>= 20` a
finding, identical descriptions worst. Exit 0; `--json`, `--threshold`, `--prefix-ratio`, `--top`.

Two design traps it encodes, both repeats of earlier lessons in this file:
- **Never compare roots against each other** — the first version reported all 21 `atlas-X` bridged skills
  as colliding with their own source `X`. One root = one routing surface.
- **Only discoverable skills** — `.archive/`, `.hub/quarantine/`, `.git/`. Including them reported `ctf-web`
  colliding with a quarantined copy of itself, and 3 of the 6 "bug-bounty template" collisions were
  archived skills that never load. Verified with a synthetic 4-skill fixture before trusting the output.

### 2.4 `~/.hermes/SOUL.md` — two always-resident invariants
Added under the identity paragraph (118 → ~230 words, still one screen):
- **Verify by reading the artifact back, never by the step's own exit code** (a dead scanner reports zero
