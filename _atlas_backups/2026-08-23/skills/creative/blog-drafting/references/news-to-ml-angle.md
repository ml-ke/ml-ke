# News-to-ML Angle Conversion Pattern

When a major business or infrastructure investment is announced, extract the ML angle systematically.

## Pattern

1. **Identify data infrastructure** — cloud migration, IoT deployment, data lakes, API strategy
   - E.g., Dangote CIO moved to 95% cloud — the foundation for ML exists
2. **Find comparable ML ROI from global peers** — what did similar companies achieve?
   - E.g., Marathon Petroleum saved $300M/yr with predictive maintenance
3. **Calculate opportunity at local scale** — apply peer ROI to the company's actual metrics
   - E.g., Reliance improved margins $1.20/barrel → Dangote at 650K bpd = $285M/yr
4. **Structure as actionable use cases** — 3-5 specific ML applications with code snippets
   - Predictive maintenance, process optimisation, supply chain, computer vision
5. **Map to ML skills** — connect the use cases to skills African ML practitioners need

## Example: Dangote $46B Expansion

Used in the Aug 5, 2026 post "AI at Industrial Scale":
- Foundation: 95% cloud, IoT sensors deployed, unified data lake
- Peer benchmarks: Marathon Petroleum (refinery PM), Reliance (process optimisation)
- Angle: $46B = $46B ML opportunity
- Skills mapped: time-series, CV, RL, graph ML, MLOps
