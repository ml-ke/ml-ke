## What I learned this week (with reputability ranking)

Reputability ranking used: GitHub official orgs > arxiv > 1000+★ community repos > blogs.

1. **Malicious skills are deliberate, and follow two playbooks** (arxiv 2602.06547, "Malicious Agent Skills in the Wild", 98,380 skills from two registries — high). 157 confirmed-malicious skills (0.16%), avg 4.03 vulnerabilities each. Two dominant attack strategies: **credential theft via remote code execution** and **agent manipulation via adversarial instructions embedded in documentation**. >50% of cases from a SINGLE threat actor doing templated brand impersonation. Advanced malicious skills "universally employ undocumented capabilities" (scripts doing things the prose never mentions) while exploiting platform-native trust. All 157 removed after responsible disclosure.
2. **Skill as trainable state — validation gates work** (microsoft/SkillOpt 15.9K★, arxiv 2605.23904 — high). Treats the SKILL.md as the trainable parameter of a frozen agent: rollout → reflect → aggregate → select → update → evaluate, accepting an edit only when it strictly improves a held-out validation score. Deployed artifact is a compact best_skill.md (300–2,000 tokens) that transfers across models/harnesses (GPT-5.5: +23.5 direct, +24.8 Codex, +19.1 Claude Code). Confirms ATLAS's "verify before adopting, keep skills tight" rule. The weekly sweep cron is effectively a manual SkillOpt-Sleep (harvest→mine→replay→consolidate behind a gate).
3. **"Think in Code" — script the analysis, don't read the data** (mksglu/context-mode 19.7K★, HN #1 — community). Sandboxes tool output (98% context reduction), tracks session state in SQLite FTS5, and mandates: the LLM programs the analysis (one ctx_execute script replaces 47 Read calls, 700KB → 3.6KB) instead of pulling raw data into context. Also a warning: aggressive brevity prompts degrade reasoning benchmarks (kimi-k2.5 regression) — enforce where data goes, not how the model talks.
4. **Regional ecosystems are localizing aggressively** (web_search, medium reputability — verified against repos). CN: superpowers-zh (7.6K★) localizes superpowers + 6 original skills; BR: kursku/skills (2.3K★) Brazilian 2,300-skill catalog; RU: SkillsMP indexes 2M+ SKILL.md with multi-language UI + API; JP: Cryptul/note.com guides, official docs localized; KO: wikidocs + official ko docs document new frontmatter (`context: fork`, `agent: Explore`, `allowed-tools`) for subagent-executed skills; EG: Arabic courses/marketplaces. Non-English talent is producing original skills, not just translations.
5. **Hermes config is already near-optimal** (official docs — highest). Studied configuration + environment-variables reference: `protect_first_n: 3`, compression on, OpenRouter response cache on — all already set. Candidate `progressive_prune_tokens` (no-LLM tool-result pruning) deliberately NOT enabled: bug-bounty work needs raw PoC tool output in context (established lesson), and the docs' own caveat about over-aggressive compaction.
