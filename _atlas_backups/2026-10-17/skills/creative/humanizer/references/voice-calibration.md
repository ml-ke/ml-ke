# Voice calibration (optional)

Run this when the user supplies a sample of their own previous writing. Skip it otherwise — the default voice lives in SKILL.md's PERSONALITY AND SOUL section.

## 1. Read the sample first

Note:

- Sentence length patterns (short and punchy? Long and flowing? Mixed?)
- Word choice level (casual? academic? somewhere between?)
- How they start paragraphs (jump right in? Set context first?)
- Punctuation habits (lots of dashes? Parenthetical asides? Semicolons?)
- Any recurring phrases or verbal tics
- How they handle transitions (explicit connectors? Just start the next point?)

## 2. Match their voice in the rewrite

Don't just remove AI patterns — replace them with patterns from the sample. If they write short sentences, don't produce long ones. If they use "stuff" and "things," don't upgrade to "elements" and "components."

## 3. No sample provided

Fall back to the default behavior: natural, varied, opinionated voice.

## How to ask for a sample

- Inline: "Humanize this text. Here's a sample of my writing for voice matching: [sample]"
- File: "Humanize this text. Use my writing style from [file path] as a reference."
